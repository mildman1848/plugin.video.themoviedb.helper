# Contributing

Deutsch: [CONTRIBUTING.DE.md](CONTRIBUTING.DE.md)

Thanks for contributing.

## Workflow

1. Base all fork-specific work on `mildman/headless-libsync`.
2. Keep commits focused and small.
3. Run local checks before opening a PR.
4. Update documentation and changelog when behavior changes.

## Upstream Sync

Do not commit fork patches directly to `nexus`.
Follow [UPSTREAM-SYNC.md](UPSTREAM-SYNC.md) for update procedures.
