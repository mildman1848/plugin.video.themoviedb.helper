## Purpose

- Keep upstream-compatible TMDb Helper sources.
- Maintain headless Kodi/Docker compatibility patches in our custom branch.
- Publish stable fork releases through the `mildman1848.github.io` Kodi repository.

## Branch Model

- `nexus`: upstream mirror branch (no custom commits)
- `mildman/headless-libsync`: custom branch for fork changes

For sync/update commands, see [UPSTREAM-SYNC.md](UPSTREAM-SYNC.md).
