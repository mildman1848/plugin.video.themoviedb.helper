# Sicherheitsrichtlinie

English: [SECURITY.md](SECURITY.md)

Bitte melde Sicherheitsprobleme verantwortungsvoll und vertraulich.

## Meldung

- Eröffne eine private Security Advisory auf GitHub, oder
- kontaktiere den Maintainer über GitHub.

Bitte angeben:

- betroffene Version
- nachvollziehbare Reproduktionsschritte
- Einschätzung der Auswirkung
- mögliche Gegenmaßnahme (falls bekannt)
